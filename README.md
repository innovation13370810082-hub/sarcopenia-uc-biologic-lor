# Body Composition and Treatment Outcomes

## Overview

This repository contains the R code used for the statistical analyses and figures in a study evaluating associations between body-composition characteristics and treatment outcomes.

Cox proportional hazards regression was performed in IBM SPSS Statistics. R was used to create the Cox regression forest plot, perform Kaplan–Meier analysis, conduct overlap-weighting sensitivity analysis, calculate Spearman correlations, evaluate the incremental predictive value of an additional exposure variable, and generate publication-quality figures.

The original patient-level dataset is not publicly available because it contains confidential clinical information. Variable names and file paths in the public code have been anonymized.

## R scripts

### `plot_cox_forest.R`

Creates a publication-style forest plot from Cox regression results previously calculated in IBM SPSS Statistics. The input CSV should contain the following columns:

```text
Characteristic, HR, lower, upper, P
```

This script does not fit a Cox regression model in R.

### `plot_kaplan_meier_curve.R`

Fits Kaplan–Meier curves for two exposure groups, performs the log-rank test, and displays confidence intervals and a number-at-risk table.

### `overlap_weighting_analysis.R`

Performs propensity score overlap weighting using the average treatment effect in the overlap population (`estimand = "ATO"`). The script includes:

- estimation of overlap weights;
- assessment of covariate balance;
- a Love plot;
- propensity score distribution plots;
- Jensen–Shannon divergence;
- an overlap-weighted Cox model; and
- an overlap-weighted baseline characteristics table.

### `spearman_correlation_analysis.R`

Calculates pairwise Spearman correlation coefficients and P values, creates a correlation heatmap, and generates selected correlation scatterplots with LOESS smooth curves.

### `model_increment_analysis.R`

Compares a base Cox model with an extended model containing one additional exposure variable. The analyses include:

- likelihood-ratio testing of nested models;
- apparent and optimism-corrected C-index;
- bootstrap internal validation;
- time-dependent AUC and ROC analysis; and
- tabular and graphical summaries of incremental model performance.

Bootstrap validation of the C-index and time-dependent AUC is performed separately, using the numbers of resamples specified in the corresponding sections of the script.

### `plot_cindex_dumbbell.R`

Creates a dumbbell plot comparing the optimism-corrected C-index of the base and extended models. It reads a CSV containing the model-performance metrics generated by the model increment analysis.

## Anonymized variables

Public scripts use generic variable names such as:

```text
follow_up_time
event
exposure
covariate_01
covariate_02
...
```

The anonymized names do not reveal the corresponding clinical variables. To run the code, column names in the input data must match the names used in the relevant script. Numbered covariate names are script-specific placeholders and should not be interpreted as a clinical ranking.

## Usage

1. Clone or download the repository.
2. Open R or RStudio in the repository root directory.
3. Place appropriately formatted, de-identified input files in `data/`.
4. Ensure that the input column names match those required by the selected script.
5. Run the relevant R script from the repository root.
6. Generated figures and tables will be written to `results/figures/` and `results/tables/`.

The scripts are largely independent. However, `plot_cindex_dumbbell.R` requires the model-performance results produced by `model_increment_analysis.R` and saved in CSV format.

## Data availability and privacy
