#  Association of Sarcopenia With Subsequent Loss of Response to Biologic Therapy in Ulcerative Colitis: A CT-Based Retrospective Cohort Study

## Overview

This repository contains the R code used for the statistical analyses and figures in a study evaluating associations between body-composition characteristics and treatment outcomes.

Cox proportional hazards regression was performed in IBM SPSS Statistics. R was used for graphical presentation and supplementary analyses, including Kaplan–Meier analysis, overlap weighting, Spearman correlation analysis, and evaluation of incremental model performance.

The original patient-level dataset is not publicly available because it contains confidential clinical information. Variable names and file paths in the public scripts have been anonymized.

## R scripts

### `forest_plot_cox_regression.R`

Creates a publication-style forest plot using Cox regression results previously calculated in IBM SPSS Statistics. The input CSV should contain:

```text
Characteristic, HR, lower, upper, P
```

This script visualizes previously calculated results; it does not fit the Cox regression model in R.

### `plot_kaplan_meier_curve.R`

Fits Kaplan–Meier curves for two exposure groups, performs the log-rank test, and displays confidence intervals and a number-at-risk table.

### `overlap_weighting_analysis.R`

Performs propensity score overlap weighting using the average treatment effect in the overlap population (`estimand = "ATO"`). It includes estimation of overlap weights, covariate-balance assessment, a Love plot, propensity score distribution plots, Jensen–Shannon divergence, an overlap-weighted Cox model, and an overlap-weighted baseline table.

### `spearman_correlation_analysis.R`

Calculates pairwise Spearman correlation coefficients and P values, creates a correlation heatmap, and generates selected scatterplots with LOESS smooth curves.

### `model_increment_analysis.R`

Compares a base Cox model with an extended model containing one additional exposure variable. It includes nested-model likelihood-ratio testing, apparent and optimism-corrected C-index, bootstrap internal validation, time-dependent AUC and ROC analysis, and tabular and graphical summaries of incremental model performance.

Bootstrap validation of the C-index and time-dependent AUC is performed separately using the numbers of resamples specified in the corresponding sections of the script.

### `plot_cindex_dumbbell.R`

Creates a dumbbell plot comparing the optimism-corrected C-index of the base and extended models. It reads a CSV containing the model-performance metrics generated by the model increment analysis.

## Anonymized variables

The public scripts use generic names such as:

```text
follow_up_time
event
exposure
covariate_01
covariate_02
...
```

These names do not disclose the corresponding clinical variables. To run a script, the input data columns must match the anonymized names used in that script. Numbered covariates are placeholders and should not be interpreted as a clinical ranking.

## Usage

1. Clone or download this repository.
2. Open R or RStudio with the repository root as the working directory.
3. Create the following local directories if required by the selected script:

```text
data/
results/figures/
results/tables/
```

4. Place appropriately formatted, de-identified input files in `data/`.
5. Ensure that the input column names match those used in the relevant script.
6. Run the selected R script.
7. Generated figures and tables will be written to the corresponding directories under `results/`.

The scripts are largely independent. However, `plot_cindex_dumbbell.R` requires model-performance results generated by `model_increment_analysis.R` and saved in CSV format.
